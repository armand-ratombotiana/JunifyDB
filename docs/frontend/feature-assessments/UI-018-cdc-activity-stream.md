# UI Feature Assessment: Change Data Capture (CDC) Activity Stream

## Feature ID
`UI-018`

## Assessment Date
September 9, 2026

## Repository Commit
`e6bbecb`

## Related Vision Goal
Real-time streaming replication and event-driven architectures.

## User Problem
Users need to observe change data capture events as they occur across collections and buckets.

## User Capability
View real-time event log of database mutations (INSERT, UPDATE, DELETE) with timestamps and payloads.

## Expected User Journey
User navigates to `#logs` tab, selects "CDC Stream", live list of mutations streams in chronological order.

## Entry Point
`#logs` navigation tab.

## Route
`/index.html#logs`

## Page or Screen
Logs & CDC Inspector View

## Components Involved
`#tab-logs`, `#cdcLogList`, `#cdcStatusBadge`, `#cdcFilterInput`

## UI Actions
View live feed, pause/resume feed.

## Frontend State
Buffered CDC events array.

## API Client
`GET /api/cdc/events` or `GET /api/cdc`

## HTTP Method
`GET`

## Endpoint
`/api/cdc/events`

## Request Parameters
Optional `Since` timestamp header.

## Request Payload
None

## Required Headers
`Accept: application/json`

## Authentication Requirements
Inherited from session cookie.

## Backend Service
`CDCHandler` & `CDCManager`

## JNOSQL-EMBED Library API
`CDCManager.processor().getEventsSince()`

## Storage Engine
In-memory CDC ring buffer.

## Expected Database State
Read-only event stream query.

## Response Contract
`{ "events": [ { "type": "INSERT", "collection": "orders", "id": "1", "timestamp": 1694240000 } ] }`

## UI Rendering Contract
Renders color-coded event cards (green for INSERT, blue for UPDATE, red for DELETE).

## Acceptance Criteria

### Functional Criteria
Displays accurate mutation events in order of occurrence.

### Integration Criteria
Receives events generated by UI and background operations.

### Error Criteria
Displays reconnect indicator if connection interrupted.

### Loading Criteria
Spinner shown while initial events load.

### Empty-State Criteria
Displays "No CDC events recorded" if quiet.

### Validation Criteria
Valid JSON return format.

### Security Criteria
Sanitizes event payload display.

### Accessibility Criteria
Event list structured with semantic `<ol>` and `<li>`.

### Responsive Criteria
Event cards collapse details on mobile viewports.

### Performance Criteria
Streams events with < 50ms latency.
